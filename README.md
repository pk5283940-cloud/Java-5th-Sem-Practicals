# Java 5th Semester Practicals (1-10)

This repository contains solutions to the ten Java practical exercises.

## Contents
1. Classes and Objects
2. Single, Multilevel, and Hierarchical Inheritance
3. Multiple and Hybrid Inheritance Using Interfaces
4. Method Overloading and Method Overriding
5. Simulating Operator Overloading Using Methods
6. Default, Parameterized, and Copy Constructors
7. Object Lifecycle and Garbage Collection
8. Constructor Overloading
9. `this`, Constructor Chaining, and Static Members
10. Encapsulation and Validation

## Requirements
- JDK installed (Java 8 or later recommended)
- Terminal / Command Prompt

## Compile and run
Open a terminal in this folder. For example, to run Practical 1:

```bash
javac Practical1.java
java Practical1
```

Repeat with `Practical2.java` through `Practical10.java`.

Each practical is self-contained. The source files include brief explanations in comments.
